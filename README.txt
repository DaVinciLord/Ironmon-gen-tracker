IronMON Tracker — Generation 1

REQUIREMENTS
- BizHawk 2.8 or newer with a Game Boy core (Gambatte or GBHawk)
- mGBA is not supported

SUPPORTED GAMES
- Pokémon Red (US/EU)
- Pokémon Blue (US/EU)
- Pokémon Yellow (US/EU)
- Pokémon Yellow (France)
ROMs must be .gb or .gbc. Optional matching UPR ZX log: <rom>.gb.log or <rom>.gbc.log

BIZHAWK USAGE
1. Open BizHawk and load a supported Game Boy ROM
2. Tools -> Lua Console
3. Script -> Open Script
4. Open Ironmon-Tracker.lua from this folder

NEW RUN / QUICKLOAD
Place randomized .gb/.gbc files (and their .log files) in the folder configured under Tracker Setup -> New Run. See the quickload folder for extra notes.

This tracker is a Generation 1 adaptation of Besteon's Ironmon Tracker.
